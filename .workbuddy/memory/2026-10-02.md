## 裸 TCP 练手脚本（诊断 ConnectionRefusedError）

- 用户自写 `test1.py` 连 127.0.0.1:8899 报 `ConnectionRefusedError [WinError 1225]`。
- 诊断结论：8899 端口上**没有任何程序监听**（netstat 确认），不是代码或防火墙问题。
- 新增 `test1_server.py`（asyncio.start_server 回显服务端，故意分两次 write 制造半包）
  与 `test1_client.py`（加固版客户端：连接失败给人话提示、带 read 超时、支持端口/内容参数）。
- 实测：服务端在跑时原版 test1.py 能收全；注意服务端若 `echo(...)` 前缀与正文分两次 write，
  客户端单次 `read(1024)` 可能只拿到前半段——这正是 Message 边界问题的直观演示。
- README 已补「顺手练手：裸 TCP 回显」小节。
